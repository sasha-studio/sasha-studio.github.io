# Adventure Island assets

The browsable asset categories are `maps/`, `game-ui/`, and `elements/`. Each folder contains numbered WebP images with an `ASSET-INDEX.md` matching the viewer order. The separate `letters/` folder supplies the interactive A–Z character showcase. The cover is `adventure-island-cover.webp`.

To add artwork, use the next number in the correct folder, update its index, then add its title, alt text, and file path to the matching category in `src/data.js`. Original full-resolution PNGs are preserved under `source-assets/adventure-island/New assets`.
