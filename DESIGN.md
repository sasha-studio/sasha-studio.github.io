# Visual direction — Sasha Makarov

## Intent

A professional game artist portfolio with the warmth and appeal of feature-animation visual development. Expressive characters and cinematic worlds take priority; editorial work remains clearly accessible. The site is English-language. No Disney affiliation or client credits are implied.

## Palette

| Role | Colour |
| --- | --- |
| Night / header / footer | `#10172c` |
| Warm paper | `#faf7f0` |
| Text | `#272b43` |
| Starlight / primary action | `#edc887` |
| Lavender | `#e9e3f1` |
| Secondary text | `#68687a` |

Fraunces headlines add storybook personality without imitating a studio logo. DM Sans supports clear reading. Art supplies the saturated colour; surrounding panels stay quiet.

## React Bits selections

BlurText, FadeContent, and TiltedCard were selected from the official React Bits source. They are adapted locally, with attribution and the full upstream license retained. Text uses a short blur reveal; sections enter once; covers use gentle springs. Mobile and reduced-motion paths remain static and navigable.

## Content hierarchy

1. Cinematic introduction and portfolio CTA.
2. Featured game world.
3. Character and game UI concepts.
4. Graphic design: documents, cards, presentations.
5. Artist introduction, process, and contact.

## Asset provenance

`moonlit-kingdom.webp` and `woodland-friends.webp` were generated for this visual direction on 2026-09-15, then format-compressed without changing composition. They are clearly identified as sample art and should be replaced by Sasha's actual work. The UI and paper studies are authored locally in `Artwork.jsx` and CSS. No supplied client material or reference-portfolio images were copied.
