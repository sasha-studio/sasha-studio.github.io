# Adventure Island assets

The browsable asset categories are `maps/` and `elements/`. Each category contains only images supplied in the latest `New assets` folder; filenames match the viewer order and each folder has an `ASSET-INDEX.md`. The separate `letters/` folder supplies the interactive A–Z character showcase. The cover is `adventure-island-cover.webp`.

To add category artwork, use the next number in the correct folder, update its index, then add its title, alt text, and path to the matching category in `src/data.js`. Original full-resolution PNGs are preserved under `source-assets/adventure-island/New assets`.
