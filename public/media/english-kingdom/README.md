# English Kingdom portfolio assets

Images are grouped into numbered category folders. File names start with the display order inside that category.

To add an image, place it in the appropriate category folder and give it the next number (for example, `21-new-scene.webp`). Then add its title, alt text, and path to the matching category in `src/data.js` so it appears in the website viewer. Keep the source Figma file unchanged.

- `02-monster-drops/` — 1 images
